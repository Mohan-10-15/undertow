    How this works

    By default, Undertow runs entirely in your browser and nothing you scan is sent anywhere. It checks the same categories a security analyst looks at first:

    Structure

    Raw IP addresses, stacked subdomains, encoded characters, unusual length.

    Impersonation

    Misspelled or look-alike versions of known brands, numbers swapped for letters.

    Pressure tactics

    Urgency, generic greetings, requests for passwords, codes, or card numbers.

    This is a heuristic screening tool built for quick triage — not a guarantee. It has not been validated against a real-world phishing dataset, so treat the score as a set of reasons to look closer, not a verdict. If you add a Safe Browsing key, that check adds real, continuously-updated threat data — but it's called directly from your browser with your own key, which is fine for personal use and not how a multi-user product should be built (see the README for why). When in doubt, verify through a channel you already trust, like typing the organization's known address directly into your browser.

    Undertow runs client-side by default. Nothing is logged or transmitted unless you enable the optional external check.
